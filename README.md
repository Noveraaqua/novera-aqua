# NOVERA AQUA

Shrimp tank monitoring dashboard with interactive 2D Tank World.

Static HTML/CSS/JavaScript site, hosted from main / (root) using GitHub Pages.

Records are saved in each browser's local storage, not GitHub. To move existing records to this website, use Setup → Backup and restore on the old site, then restore the backup on the new site. Do not commit backups to this public repository.

Run checks: `node tests/tank-world.cjs`.

See TANK-WORLD-README.md for implementation details.
